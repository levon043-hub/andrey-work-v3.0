# Андрей Work версия V3.0

Личный сайт Андрея — веб-дизайн и разработка сайтов под ключ.

Интерактивная обложка с семью проектами, оригинальной 3D-моделью «А», лаймовым светом и адаптивной галереей. В версии V3.0 модель уменьшена на 30%, а композиция работ выровнена.

## Запуск

```sh
python -m http.server 5173 --bind 127.0.0.1 --directory dist
```

Откройте http://127.0.0.1:5173/.

## Технологии

HTML / CSS / JavaScript / Three.js 0.186.1. Сайт статический, сборка не требуется. Папка `dist` содержит готовую версию для размещения. Three.js распространяется по MIT; лицензия находится в `dist/vendor/THREE-LICENSE.txt`.

Поддерживаются мобильная галерея, просмотр скриншотов, управление с клавиатуры, пауза анимации и системная настройка уменьшения движения.
